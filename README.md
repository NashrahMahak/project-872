# CCGC 5502 - Azure Terraform Infrastructure Project

This repository contains the Terraform configuration files and modules for provisioning and managing Azure cloud infrastructure resources for the CCGC 5502 Automation project.

## Repository Structure
- `modules/`: Custom Terraform modules for networking, security, storage, and compute.
- `main.tf`: Root configuration module definitions.
- `providers.tf`: AzureRM provider configuration.
- `backend.tf`: Azure Blob Storage remote backend configuration.
- `outputs.tf`: Terraform output variable definitions.
